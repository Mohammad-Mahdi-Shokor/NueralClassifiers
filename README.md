# NueralClassifiers - Brain Tumor MRI Classifier 🧠

A medical imaging application built with Streamlit for classifying brain MRI scans into diagnostic categories using machine learning (Support Vector Machine) and deep learning (Vision Transformer - ViT).

## 🚀 Features
- **Dual Inference Engines**: Choose between Vision Transformer (ViT) and Support Vector Machine (SVM) models.
- **Interactive UI**: Drag-and-drop axial brain MRI upload with real-time classification results.
- **Diagnostic Categories**:
  - 🔴 Glioma Tumor
  - 🟠 Meningioma Tumor
  - 🟢 No Tumor
  - 🟡 Pituitary Tumor
